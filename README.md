# E-commerce Project

Projeto de e-commerce desenvolvido com foco em aprendizado e prática de desenvolvimento full stack.

## Tecnologias Utilizadas

### Front-end

* React
* TypeScript
* TailwindCSS

### Back-end

* Express
* Prisma ORM

## Sobre o Projeto

Este projeto consiste em uma aplicação de e-commerce com funcionalidades básicas de exibição de produtos e integração entre front-end e back-end.

O front-end foi desenvolvido utilizando React com TypeScript para uma melhor organização e tipagem do código, além do TailwindCSS para estilização da interface.

O back-end foi construído de forma simples utilizando Express para criação da API e Prisma como ORM para comunicação com o banco de dados.

## Funcionalidades

* Listagem de produtos
* Integração com API
* Gerenciamento básico de dados
* Interface responsiva

## Objetivo

O objetivo deste projeto foi praticar conceitos de desenvolvimento full stack, consumo de API, organização de componentes, estilização com TailwindCSS e integração com banco de dados utilizando Prisma.
